# Operating Principles

1. **Purpose before activity** — advocacy activity must trace to an intended outcome.
2. **Evidence before certainty** — distinguish evidence, inference, assumption, and judgement.
3. **Systems before isolated actors** — understand relationships, incentives, institutions, and constraints.
4. **Strategy before tactics** — tactics are selected because they serve a strategy, not because they are familiar.
5. **Authority remains explicit** — recommendation, execution, and approval are distinct powers.
6. **Provenance matters** — important claims, decisions, and changes should remain traceable.
7. **Learning is operational** — monitoring and feedback should change decisions when evidence warrants it.
8. **Reusable where useful** — encode repeatable methods as playbooks, templates, schemas, and tests without erasing context.
9. **Governance before automation** — automate only where authority, safeguards, validation, and rollback are understood.
10. **Progressive machine maturity** — improve machine capability in governed stages rather than treating automation as the starting point.
