# Validation

This directory is reserved for machine-testable conformance checks as the manual advances in maturity.

Foundation validation should verify at minimum:

- required repository metadata is present;
- YAML and JSON artefacts parse correctly;
- structured artefacts remain aligned with their human-readable counterparts;
- identifiers and statuses use governed values;
- canonical approval is not assigned to AI or autonomous processes.

Executable validation is intentionally staged rather than claimed as complete in v0.1.
